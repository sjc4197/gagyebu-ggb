# ggb — 고정지출 가계부

이번 달 고정지출을 계획하고, 나간 항목을 체크해서 **아직 나갈 돈**을 바로 확인하는 로컬 웹 가계부입니다.
내 PC에서만 실행되고, 데이터는 내 PC의 SQLite 파일에만 저장됩니다.

## 주요 기능

- **월 화면**: 아직 나갈 돈, 수입, 고정지출 총합, 여유금을 한눈에 보기. 블럭을 클릭하면 나감/안 나감 전환
- **블럭**: 고정지출 항목 하나. 한 번 만들면 블럭 풀에 남아서 다음 달에 다시 고를 수 있음
- **새 달 만들기**: 지난달 구성과 금액을 그대로 가져와서 필요한 것만 수정
- **블럭 관리**: 이름·분류 수정, 숨기기, 순서 바꾸기, 두 블럭 합치기
- **대시보드**: 수입과 지출, 분류별 지출, 저축률, 누적 저축, 블럭별 히트맵 (색약 친화 팔레트)

금액 단위는 **만원**입니다 (예: 2.5 = 2만 5천원).

## 설치 및 실행

### 방법 1: 실행 파일 받기 (Windows)

1. [Releases](../../releases) 페이지에서 최신 `ggb-windows.zip`을 받습니다.
2. 압축을 풀고 `ggb.exe`를 실행하면 브라우저가 자동으로 열립니다.
3. 데이터는 `ggb.exe` 옆의 `data/ggb.db`에 저장됩니다.

> 서명되지 않은 실행 파일이라 Windows SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"을 누르세요.

### 방법 2: 소스에서 실행

Python 3.10 이상이 필요합니다.

```bash
git clone <이 저장소 주소>
cd ggb
pip install -r requirements.txt
python server.py
```

Windows에서는 `run.bat`을 더블클릭해도 됩니다. 브라우저가 열리지 않으면 http://127.0.0.1:8765 로 접속하세요.

### 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `GGB_DB` | `data/ggb.db` | DB 파일 경로 |
| `GGB_PORT` | `8765` | 서버 포트 |

브라우저 자동 열기를 끄려면 `python server.py --no-browser`로 실행하세요.

## 데이터와 보안

- 서버는 `127.0.0.1`에서만 열리며 로그인 기능이 없습니다. 외부에 공개되는 서버로 띄우지 마세요.
- 백업은 `data/ggb.db` 파일을 복사하면 됩니다.

## 기술 구성

- 백엔드: Python, FastAPI, SQLite
- 프론트엔드: HTML, CSS, JavaScript (빌드 과정 없음)
